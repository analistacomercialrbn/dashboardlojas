# Arquivo de cópias antigas

Cópias antigas e datadas das telas e de partes do servidor, guardadas só como histórico.

- Nada aqui é usado pelo sistema na versão principal (`main`).
- As telas que o Apps Script carrega apontam para **versões fixas** (commits) do repositório.
  Esses endereços continuam funcionando mesmo depois da mudança de pasta, porque
  cada versão fixa guarda os arquivos no lugar em que estavam naquela época.
- O código do servidor que vale hoje é o `../Code.gs` (cópia fiel do "Código" do Apps Script).
- A tela em uso hoje é a `../zoom-mapas-20261109/`. Ela também usa `../gas-app.css`
  e `../sac-importacao-20261108/tower.css`.

Antes de reaproveitar algo daqui, confira se ainda faz sentido com o `Code.gs` atual.
